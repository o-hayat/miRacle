# Data provenance

The runtime app is offline. These upstream resources were downloaded during project preparation on 2026-09-26.

|---|---|---|

| `assets/references/hsa_mature.fa` | [MirGeneDB 3.0 human mature FASTA](https://www.mirgenedb.org/fasta/hsa?mat=1) | Curated mature-arm display after a near-exact known precursor match |

| `assets/references/pab_precursors_mirgenedb.fa` | [MirGeneDB 3.0 Sumatran-orangutan precursor FASTA](https://www.mirgenedb.org/fasta/pab?pre=1) | 485 orangutan precursors for independent post-ranking similarity only |

| `artifacts/raw/Rfam.seed.gz` | [Rfam current seed archive](https://ftp.ebi.ac.uk/pub/databases/Rfam/CURRENT/Rfam.seed.gz) | Preparation-only source for structured non-miRNA decoys; intentionally git-ignored |

| `artifacts/raw/chr22.fa` | [UCSC hg38 chr22 FASTA](https://hgdownload.soe.ucsc.edu/goldenpath/hg38/chromosomes/chr22.fa.gz) | Training/validation genomic negative candidates; intentionally git-ignored |
| `assets/examples/mir21_region.fa` | [UCSC sequence API](https://api.genome.ucsc.edu/) | GRCh38 chr17:59,840,773–59,841,772 positive-control region |

| `assets/examples/external_ncbi_mirnas/*.fa` | [NCBI Nucleotide/RefSeq](https://www.ncbi.nlm.nih.gov/nuccore/) accession-versioned human microRNA records | Seven external positive controls absent in both orientations from all local model sources; NCBI marks them `PROVISIONAL REFSEQ` |
| `assets/examples/external_ncbi_mirnas_flanked/*.fa` | [NCBI Gene and Nucleotide E-utilities](https://www.ncbi.nlm.nih.gov/books/NBK25501/) | Exact GRCh38 precursor sequence plus 500 genomic nt on each side for all seven external controls; coordinates and strands are frozen in the folder manifest |
| `assets/ncbi_external_machinery_mirnas.fa` | Combined copy of the seven external NCBI controls | Convenient top-level asset containing all seven precursor sequences |
| `assets/ncbi_external_machinery_mirnas.csv` | NCBI records plus linked primary studies | Self-contained top-level dataset with precursor and mature sequences, machinery proteins, experimental methods, PubMed links, and model-exclusion status |
| `assets/references/external_machinery_interactions.csv` | Candidate-specific AGO2 RIP and simtron-processing primary studies | Detailed display evidence for DROSHA, DGCR8, XPO5, DICER1, and AGO2; never used as a model feature or label |
| `assets/references/literature_summaries.csv` | Manually summarized primary literature with PubMed links | Small, offline context cards for strong human reference matches; never generated by an LLM and never used by the classifier |
| `assets/references/known_target_examples.csv` | [miRTarBase records for PDCD4](https://awi.cuhk.edu.cn/miRTarBase/records/MIRT003054/), [PTEN](https://awi.cuhk.edu.cn/miRTarBase/records/MIRT001190/), and [RECK](https://awi.cuhk.edu.cn/miRTarBase/records/MIRT000969/) | Small MIR21 demonstration subset; not an exhaustive target database |

The model does not use MirGeneDB or Rfam nearest-reference similarity as a feature. Both are computed after ranking and displayed as independent context. Rfam sequences used for model evaluation are split by family, and the bundled controls come from held-out families.

The external NCBI controls were discovered with
`Homo sapiens[Organism] AND srcdb_refseq[PROP] AND microRNA[Title]` and fetched
from NCBI E-utilities on 2026-09-26. Accession, chromosome, RefSeq status,
machinery evidence, current model result, and source URL are frozen in
`assets/examples/external_ncbi_mirnas/manifest.csv`.
